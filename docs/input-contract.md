# 原始资料契约

所有机构、车辆、单据和设备均为本地合成，不来自新闻中的真实企业，也不声称新闻发生过这些事件。

事件身份id/revision，同身份同内容为重传，异内容不覆盖。vehicle为车辆，boot为设备启动代际；新代际绝不接续旧代际。at是带时区的事件时间，业务日以Asia/Shanghai解释，文件排列为接收顺序而非发生顺序。
run、stop与complete是本代际活动，间隔不超过选定阈值时属于相接活动；间隔严格大于阈值切开。stop是有时间的停车活动，不单独关闭行程；end明确在该时刻关闭行程，之后活动开启新行程。boot事件声明新代际，不能以无活动心跳自行算一次服务。样本业务阈值为30分钟，可选择其他正值但应保存口径。
complete的appointment是id/revision明确引用，不能改认最新预约。预约修订from_at表示改派开始生效的时间；不符合被引用修订的车辆或时间进入待核实。补传可桥接间隔或补出end而改变成员，原始事件不被删除。

seed.json与同名Parquet保存相同的输入值，actions.json中的后续动作尚未处理。inventory.json只校验原件物理完整性，不是仓库目录或业务结论。所有后续仓表与接口均待开发，源码不规定其架构。
